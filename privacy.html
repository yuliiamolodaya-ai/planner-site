Политика конфиденциальности «Планер»

Планер — личное приложение для macOS, которым пользуется только его автор.

Какие данные Google используются

  • Адрес электронной почты аккаунта — чтобы показать, какой аккаунт подключён.
  • Список календарей и события — только для показа в колонке «Календарь» приложения.
  • Календарь «Планер», созданный приложением, — для записи тайм-блоков задач. Другие календари приложение не изменяет.

Где хранятся данные

Токены доступа Google хранятся только на компьютере пользователя. События календаря не сохраняются и не передаются третьим лицам; они запрашиваются у Google при показе.

Передача данных

Данные Google не продаются, не передаются и не используются для рекламы или обучения моделей. Использование данных соответствует Google API Services User Data Policy, включая требования Limited Use.

Как отозвать доступ

Отключить аккаунт можно в настройках приложения или на странице myaccount.google.com/permissions.
